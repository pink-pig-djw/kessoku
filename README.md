# 孤独摇滚！ 第五条音轨

## 下载

Windows 安装版、Windows 免安装版和 Android APK 均可在 [GitHub Releases](https://github.com/pink-pig-djw/kessoku/releases/latest) 下载。源码可直接在仓库查看；浏览器版下载源码 ZIP 后打开 `index.html`。

《孤独摇滚！》（ぼっち・ざ・ろっく！）的**非官方同人视觉小说**。

> 在 live house 里，最好的 PA 是没人注意到的那个人。
> 一个只想当「透明人」的少年，在 STARRY 的调音台后面，替四个孤独的女孩录下她们的第一盘小样。

- 时间：原作第一学年，2017 年 10 月 ~ 12 月 31 日（秀华祭之后），尾声在 2018 年春。
- 主人公：水野透，秀华高中 1 年 2 班，STARRY 的新打工生（PA 助手）。父亲以前在下北泽开录音室。
- 女主：后藤一里、伊地知虹夏、山田凉、喜多郁代。

## 怎么玩

用浏览器（推荐 Chrome / Edge）打开 `index.html` 即可。

如果浏览器拦截了本地文件，在这个文件夹里运行一个本地服务器，再访问 `http://localhost:8766`：

```bash
python tools/serve.py 8766
```

## 体量

## 结构

```
第一章 透明少年 → 第二章 四条音轨 → 第三章 啸叫 ─┬ 一里线（第四~六章 + 终章「一米之内」）→ 一里 END「你好，透明人间」
                                              ├ 虹夏线（…… + 终章「休止符」）→ 虹夏 END「替你数拍子的人」
                                              ├ 凉线  （…… + 终章「底噪」）  → 凉 END「借你一辈子」
                                              ├ 喜多线（…… + 终章「没有滤镜」）→ 喜多 END「郁代」
                                              └ 普通线（第四~六章）→ NORMAL END「第五条音轨」
```

- **好感度系统**：共通线（第一~三章）的选择会累积四位女主的好感度，每人最多 7 点。选到加好感的选项时，右上角会弹出「♥+1」；快捷栏的「好感」（或 G 键）可以随时查看。
- 第三章结尾（12 月 5 日深夜）的分歧里，**好感度达到 4 点的女主才能进入她的个人线**；不足的会显示为锁定选项「🔒 好感度不足」。「谁也不找」随时可选，进入普通线。**好感度永久累计**：每个加好感的选项只要选过一次就会记住。用分支图回到以前的选项改选别人，已经得到的好感度不会减少，新的好感度会叠加上去（同一个选项不会重复加，每人最多 7 点）。所以第一遍一般只能进一两位女主的线，之后回溯补选，就能解锁其他人。
- **终章（恋人篇）**：四条恋爱线在第六章告白之后，各有一章「终章」，写两个人在一起之后的 2018 年 1~4 月——情人节、白色情人节、见家长……每一章都有一个只属于那条线的小问题，最后接上春天的尾声。
- **分支图**：标题画面或游戏中都能打开。走过的场景会亮起，点一下就能回到那个时刻重新选择；没走过的显示为「？？？」。
- **标题画面**会随着你最后进入的分支换图（和音乐）；五个结局全部达成后，会换成全员的图。

## 素材

- 图像全部由 Codex 图像生成（gpt-6-sol，medium）：角色立绘（含表情差分和冬装）、背景、事件 CG、各路线的标题图。背景统一重画成平涂的动画背景画风（旧的写实版本留在 `assets/_bg_photo_backup/`）。
- 背景音乐 16 首由 Suno 生成（纯音乐，`assets/bgm/`），包括一里的主题「壁橱里的宇宙」。某首 mp3 读不到时，会自动换回 WebAudio 实时合成的版本。
- 音效和环境音由 WebAudio 实时合成。
- 剧中只提到结束乐队歌曲的歌名，不引用任何歌词。新歌「ハウリング」是本作原创。

## 安卓 App

从 [Releases](https://github.com/pink-pig-djw/kessoku/releases/latest) 下载 `孤独摇滚-第五条音轨.apk`（约 105MB）：传到安卓手机上点开安装（第一次需要允许「安装未知来源应用」）。横屏全屏、离线可玩，存档保存在手机里。

手机操作：点击屏幕前进 · 长按屏幕隐藏界面 · 向下滑查看记录 · 返回键关闭菜单 / 回到标题。在手机浏览器里直接打开网页版也会自动切换成手机界面。

重新打包（改了剧本或素材之后）：

```bash
bash tools/build_apk.sh
```

- 图片会自动转成 WebP（314MB → 28MB），在线字体会去掉。
- 需要 JDK 21 和 Android SDK（本机装在 `C:\Users\13857\android-tools`）；有代理时会自动读取 `HTTPS_PROXY`。
- 发布版使用本地的 `app/kessoku-release.jks` 和 `app/keystore.properties` 签名，这些私密文件不在仓库中。**以后更新 app 必须用同一个签名文件**，丢了就只能卸载重装（存档会丢）。

## Windows 版

- [Releases](https://github.com/pink-pig-djw/kessoku/releases/latest) 中的 `孤独摇滚-第五条音轨-1.0.1-win.exe`：安装程序（约 166MB），可以选安装位置，会建桌面和开始菜单快捷方式。
- [Releases](https://github.com/pink-pig-djw/kessoku/releases/latest) 中的 `孤独摇滚-第五条音轨-1.0.1-win.zip`：免安装版，解压后双击 `孤独摇滚！第五条音轨.exe`。
- 窗口 16:9，可以拉伸；**F11 或 Alt+Enter 切换全屏**。不需要联网，存档保存在本机。
- 程序没有数字签名，第一次运行时 Windows 可能弹出「Windows 已保护你的电脑」，点「更多信息 → 仍要运行」。

重新打包：

```bash
bash tools/build_win.sh
```
