# 终章（恋人篇）大纲与写手须知

四条恋爱线在告白之后只剩一个很短的春天尾声。现在要在**告白和尾声之间**插入一章「终章」，写两个人在一起之后的日子（2018 年 1 月 ~ 春天）。
不是糖水流水账。每个终章都要有自己的一个小问题：恋爱让她（和透）原本的孤独换了一种形状冒出来，最后用这条线自己的方式解决。搞笑和感动交替，和前六章同样认真。

## 先读
1. `docs/写手须知.md`（文风、演出规则、格式，全部照旧适用）、`docs/设定集.md`（称呼表、说话风格）、`docs/大纲.md` 里你那条线的部分
2. `script/01_ch1.js` `02_ch2.js` `03_ch3.js` 至少通读一遍，找回文风
3. **你那条线的整个文件**（必须全文读完）：终章里的回响、称呼、谁知道什么、物件（借款本、卡带、毯子、邀请卡……）都要和前文一致
4. `js/assets.js`（新素材已经登记好，见下）

## 结构
- 位置：告白场面结束之后、原来的尾声节点之前。章节卡：`@chapter 终章|标题|ENGLISH SUBTITLE`。
- 新标签、新节点 id 用前缀 `b7_` / `n7_` / `r7_` / `k7_`。每个场景开头一个 `@node id|短标题`。终章约 6~7 个节点。
- **原来的尾声节点（`b6_epi` / `n6_spring` / `r6_spring` / `k6_epilogue`）保留标签和 node id 不变**，它成为终章的最后一个场景。你可以改它的文字，让它接住终章里的线（不要和终章重复同一个梗，不要矛盾），但它的核心画面和最后几句要保留。结尾的 `@ending` → `@credits` → `@totitle` 不动。
- 体量：终章新增显示文本 **8000~10000 字**（`node tools/validate.js 你的文件名` 会显示整个文件的字数，写完前后各看一次）。
- 小选项：最多 2 个，只影响几句台词，不影响结局，不加好感度。
- 时间跨度：告白之后 ~ 尾声那天。日期用 `@date 2018年1月14日（周日）|晴` 这种格式。

## 演出补充规则
- 冬天出门（约会等）时进入的公共室内场所（水族馆、咖啡店、乐器店、唱片店）里，女主可以**继续穿冬装立绘**（大家进店不一定脱外套）。学校、STARRY、各家的家里，用普通立绘。同一个场景里照旧不能换装。
- 凉的父母、喜多以外的家长没有立绘：只能隔着门、电话里、或者用旁白转述，**不能在画面上直接说话**。
- 虹夏发烧卧床的场面：她只能出现在 CG `n_fever` 里（没有睡衣立绘），CG 关掉前把卧床的对话说完。
- 恋爱表现：牵手、靠肩、最多一个很轻的吻。不写任何露骨内容。
- 不要引用真实歌曲的歌词。新歌的歌词只写一两句原创的意象。
- 其他三位女主在这条线里是乐队伙伴和朋友，给她们每人至少一个好笑或温暖的小场面。修二、星歌、PA 小姐、广井可以客串。
- 透的脸永远不画清楚（CG 里已经是这样），旁白也不要写他照镜子之类的描写。

## 一里线　终章「一米之内」 WITHIN ONE METER（1/2 ~ 2/21）
核心：告白是在一米外用 LINE 打出来的。终章是把这一米缩到零——一里学会用声音说出来；透学会不只是「在那里」，而是走过去。
一里的新问题（原作味道）：**她相信自己的歌词是从孤独和壁橱的黑暗里长出来的。幸福了，就写不出歌了。**
1. `b7_group` 1/2 夜，LINE：一里想私聊约透第二天去八景岛，结果发进了「结束乐队＋1」。群里炸了（喜多「！？！？」、虹夏「波奇酱！？」、凉「恭喜。份子钱借我」）。一里连发几十个贴图想把消息顶上去，然后退群；虹夏把她拉回来。然后透收到她的私聊：「……明、明天……还算数吗……」。（可以放一个小选项：打字回 / 直接打电话）
2. `b7_aqua` 1/3 八景岛（户外先到 hakkei 或 gotoh_house 附近，再进 aquarium）。一里准备了一本照着少女漫画写的「约会对话清单」，全部失败（tint fantasy 的妄想 + 现实崩坏）。新年人多，她想逃；进了蓝色的水槽隧道，她安静了下来：「……这里，像壁橱。」（CG `b_aqua`）水里听不见声音，但透听见了水泵很低的嗡嗡声，她说她也听见了。她的小指勾住了他的袖口。回程在平潟湾，她小声说：「……现在，好幸福。……好可怕。」
3. `b7_school` 1/9 第三学期开学。一里在班上脱口叫了一声「透、透君」，同学 A、B 听见了，「诶——！？」班里第一次有人注意到透（「水野君，你和后藤同学……？」），透浑身不自在；喜多闪着光从五班冲过来，让事情更糟。午饭，楼梯底下，两个人一起吃（呼应尾声里「已经没有谁的日子了」——先确认共通线里楼梯底下的「日子」是怎么分的）。
4. `b7_block` 1 月下旬（例如 1/20 STARRY）：凉写了第二首新歌的旋律，要一里写词。一里交出来的全是幸福的流水账（「今天天气很好／透君的手很暖」这一类，好笑），凉「这是日记吧」，虹夏「……好甜」，喜多「好可爱！但是……」。一里的理论（tint despair）：再这样下去，自己会变成一个幸福的、什么都写不出来的普通人。她用 LINE 对透说「暂、暂时……不要见面」，然后「闭关」进壁橱。透被推开，心里很难受，但不追。广井（或修二）一句很清醒的话，给透指路——例如「孤独又不会消失。有人在，只是换了个形状」。
5. `b7_door` 2/3 节分。二里用妈妈的手机打给透：「姐姐的男人。姐姐变成蘑菇了。」透去金泽八景。撒豆子的闹剧（直树戴鬼面具、二里、美智代、吉米亨）。然后一里的房间，壁橱的门关着。透坐在门外，隔着门说话（CG `b_door`）——这次换他说：他在三个视频之前就听见她了；他自己也躲了很多年（母亲离开、调音台后面、「透明」）；他也怕——幸福被录下来就会被听见、被评判。「孤独不是你的声音。是你的声音撞上的墙。墙还在。我又不会拆你的壁橱。」门开了一条缝，从缝里递出来一张纸：今晚写的歌词，不是幸福也不是孤独，是「害怕幸福」的歌（只写一两句原创意象）。最后门开了，一里连人带吉他摔出来（好笑又甜），二里在门口看：「姐姐的男人，好厉害。」
6. `b7_choco` 2/14 情人节，楼梯底下。一里的巧克力（美智代帮忙做的，形状是拨片，结果……）。她习惯性地拿出手机想打字，打了一半，删掉，**用声音**说：「……请、请收下。」——这是一米缩到零的那一下。巧克力用了 99% 的可可，因为「苦＝摇滚」，好笑。第二首新歌的歌词完成，凉：「……可以。」
7. `b6_epi` 2/21 原尾声（保留：零点的新视频「mix：透明人間」、在旧评论下的第二次回复、楼梯底下送毯子、「你好，透明人间」「你好，吉他英雄」、融化）。可以让它接住终章（比如她这次说「你好，透明人间」时没有排练一百遍、或者没有打字）。

## 虹夏线　终章「休止符」 REST（1/1 ~ 4/7）
核心：虹夏一直在照顾所有人——现在也开始照顾透。她不知道怎么被人照顾、怎么为自己要一样东西。透替她数拍子，也要替她数**休止符**：鼓手也可以停下来。
1. `n7_morning` 1/1~1/2：乐队知道了（星歌已经看见了「手」）。喜多尖叫、凉「恭喜。红包借我」、一里被青春的光烧成灰。星歌在吧台审问透，立「妹妹规则」（好笑：门禁、不准在店里牵手、「她要是哭着下楼，你就别想再碰推子」），最后一句很轻的：「她九岁开始做饭。那之后，我没见过她哭着要过什么东西。」
2. `n7_date` 1/14 第一次约会，御茶水乐器街（`ochanomizu`）。虹夏做了一张手写的波点日程表（10:00~18:00 分钟级）；一整天都是她在照顾透（买饮料、整理他的围巾），手机一直在回 STARRY 和乐队的消息（凉借钱、一里在车站迷路……）。乐器店的老店员认出她：「你是……御茶水魔王的妹妹？」只有在店里试一个很贵的军鼓的那几分钟，她没有在看任何人。她说想要，但「还早呢，STARRY 的音箱要先换」。透记住了。（小选项：一里迷路时，让虹夏去接 / 透去接、让她留下多试一会儿）
3. `n7_bento` 1 月下旬（例如 1/23 休演日）：虹夏的满格日常——小样提交的资料、STARRY 春天的排期、学年末、家务，还每天给透做便当。透反过来给她做了一个便当：海苔剪成波点的饭团（呼应第四章「波点的饭团」）。她很感动，然后马上开始挑毛病（「盐放多了！」）、马上去洗碗——她不会被照顾。她咳了两声，笑着说没事。
4. `n7_fever` 2/14 情人节。她前一天做巧克力做到凌晨三点：给 STARRY 的大家、乐队、修二、广井……还有一份「本命」。下午在 STARRY 笑着发完所有的义理巧克力——然后倒下了，三十八度九。星歌把她背上楼。透上了三楼的家（`nijika_room`）。CG `n_fever`：她把那份一直揣在口袋里、被体温捂化压扁的巧克力递给他（一整天都在给别人发，找不到给他的时机）。「本来想好好地给你的……」「乱掉了也没关系。」她第一次为自己要一样东西：「今天……不想当队长，也不想当妹妹。……在我睡着之前，帮我数。」透数她的呼吸。之后厨房里，星歌在煮粥（星歌立绘），两个人说话：「我不会照顾人。她会。所以一直是她在照顾我。」「……你，替我照顾她一下。」
5. `n7_snare` 3/14 白色情人节，STARRY 关门后。透的回礼：御茶水那家店的那个军鼓（用打工的钱买的二手，老店员听说是「魔王的妹妹的男朋友」给打了折）。「这个鼓，只给你自己打。」空荡荡的 STARRY，不开节拍器，不带乐队，虹夏第一次乱七八糟、开开心心地打了一段谁也不用跟的鼓；透用四轨机录下来——只有她一个人的音轨。（可以有一个很轻的吻。）
6. `n7_grave` 3/21 春分。星歌、虹夏、透去扫妈妈的墓（CG `n_grave`）。虹夏在墓前把透介绍给妈妈；星歌在墓前放了一枚拨片，说她把吉他买回来了（接尾声里「店长的房间里，多了一把吉他」）。虹夏对妈妈说：今年，她想要一样只属于自己的东西。星歌忍着眼泪（seika cry）。
7. `n6_spring` 4/7 原尾声（保留：小样三月底由虹夏提交、29 盘卡带和仓库外套的男人、修二偶尔来喝一杯、店长房间的吉他、「偶尔会睡到七点」、PA 席、「今天我可能会乱哦」「我数」、一二三四）。可以加上她的鼓上多了那个新军鼓。

## 凉线　终章「底噪」 NOISE FLOOR（1/1 ~ 4/10）
核心：凉开始诚实地写歌，透是「第一个听的人」。新问题：**喜欢一个人以后，耳朵还会不会说真话？** 以前的乐队说「好听」其实是「好卖」；透是第一个喜欢她、还会说「不好听」的人。
1. `r7_new` 1/2 初卖（新年第一天开门的二手器材店，`record_shop`）：凉拿到了一大笔压岁钱，上午就全换成了一个古董法兹效果器，中午找透借午饭钱。电话里（或回家时隔着门）向父母宣布：「……他是男朋友。」京香阿姨的尖叫、恭一叔叔的眼镜、又给奶奶打电话。父母没有立绘，不能在画面上说话。
2. `r7_band` 1/9（周二 休演日）STARRY：乐队知道了。喜多的崩溃（凉前辈和透君！？）然后自己想通（「那我就是凉前辈男朋友的同学！」）。虹夏：「凉，你要是敢跟透君借钱……」「已经借了。」一里被青春的光烧化。凉宣布：新年以后写了三首新歌，第一个听的人是透。
3. `r7_honest` 1/20：凉把第三首放给透听。透听出副歌在讨好——像是写给「要讨好的人」听的。他犹豫，然后说了真话。凉不说话，走了（「散步」）。两天已读不回（呼应第五章，但这次透不慌，他知道她会去哪）。家里的暖桌，修二只说一句：「录音师要是对乐手撒谎，那盘带子就废了。」（修二大概猜到儿子有女朋友了：「……那个奇怪的孩子？」）
