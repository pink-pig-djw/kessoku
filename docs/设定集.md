# 孤独摇滚！ 第五条音轨 —— 设定集（含剧透）

> 非官方同人视觉小说。世界观、人物、时间线遵循《孤独摇滚！》（はまじあき，芳文社）原作漫画与 TV 动画。
> 原创部分：主人公水野透及其父亲、剧情事件、乐曲「ハウリング」。**不引用任何结束乐队歌曲的歌词**（只提歌名）。

## 0. 一句话

> 在 live house 里，最好的 PA 是没人注意到的那个人。
> 一个只想当「透明人」的少年，在 STARRY 的调音台后面，替四个孤独的女孩录下她们的第一盘小样。

主题：**四种孤独，和一个躲在调音台后面的人**。
- 一里：在壁橱里尖叫，害怕被看见，又渴望被看见。
- 虹夏：看着所有人，所以没有人看着她。
- 凉：用「怪人」把自己保护起来，害怕被理解后被否定。
- 喜多：被所有人喜欢，却没有人认识真正的「郁代」。
- 透：「好的录音师，是在录音里听不出来的人。」——他把消失当成了美德。

核心意象：
- **啸叫（ハウリング / Feedback）**：声音回到自己身上、越滚越大、最后叫出来。PA 的工作是把它掐掉；吉他手有时候会故意让它叫。第六章的跨年 live 上，透第一次没有掐掉它。
- **四轨机**：一台八十年代的卡带四轨录音机。四条音轨，正好四个人。按下录音键的人，不在任何一条音轨上——他是「第五条音轨」。
- **八字绕线（over-under）**：每一圈都往和上一圈相反的方向拧，所以再长的线也不会打结。虹夏说：「像乐队一样呢。」
- **结束带**：捆电线用的扎带，日语叫「結束バンド」，和乐队同名。

## 5. 说话风格

- **透**（旁白＝内心）：冷静、克制、毒舌只在心里，常用声音和器材做比喻。台词短。
- **一里**：「啊……」「那、那个……」，自言自语用小字｛……｝，突然的奇怪发言，自我贬低，偶尔用脑内剧场（妄想）爆走。说到吉他会突然流利。
- **虹夏**：开朗、元气、「嗯嗯！」「好嘞！」，会照顾人，吐槽凉，队长口吻；偶尔笑着说出可怕的话。
- **凉**：面无表情、短句、跳跃、借钱、吃草；被说怪人会开心；关键时刻一针见血。
- **喜多**：高能量、「呀——！」、Isosta、「凉前辈♡」、社交满分；被叫郁代会炸毛。
- **星歌**：冷淡、嘴硬、「啧」，对虹夏的事反应过度。
- **PA 小姐**：敬语、慢吞吞、「……是的」，偶尔冒出意外的话。
- **广井**：醉醺醺的「诶嘿嘿～」，又突然说出很清醒的话。
- **修二**：疲惫、话少、温和，绝不说教，只在关键时说一句。

## 7. 新歌「ハウリング」（啸叫）

- 作曲：凉。作词：一里。第三章 11/28 首次出现小样（没有桥段、没有歌词）。
- 凉的想法：「最后要让吉他叫出来。」透：「啸叫是 PA 要掐掉的东西。」凉：「那就别掐。」
- 歌词主题（一里）：在壁橱里发出的声音，绕了一圈又回到自己身上，越来越大，直到有一天，被谁听见。**歌词不要全文写出来**，只写一两句意象，比如「把我的回音还给我」。
- 各线中的完成方式：一里线＝一里写下给「透明人间」的歌词；虹夏线＝虹夏写的开头鼓点 + 数拍子；凉线＝凉写完桥段并亲自唱；喜多线＝喜多弹间奏 solo；普通线＝四个人一起改完。

## 9. 剧本格式（给写手）

```
*标签名
@node 节点id|分支图上的标题          ← 每个场景开头放一个（用于可回溯的分支图）
@chapter 第一章|透明少年|TRANSPARENT BOY
@date 10月23日（周一）|晴
@bg 背景id [cut|dissolve|black|white] [毫秒] [keep]   ← 不写 keep 时会清掉立绘和特效
@show 角色 表情 [位置 l/c/r/cl/cr/ll/rr/p1~p4] [动作 hop/shake/tremble/melt/pop] [close]
@hide 角色 | @hide all
@cg 图id   /   @cg off
@bgm 曲名 | @bgm stop
@amb 环境音 | @amb stop [名字]
@se 音效
@fx sparkle|lights|confetti|dust|rain|heavyrain|snow|none    ← rain/snow 只能在户外背景
@tint fantasy|despair|memory|sepia|dark|none
@line 群名 …… 名字：消息 …… @line off          ← LINE 聊天界面；[贴图:说明] 是贴图
@mode phone|tape|normal                        ← phone：电话（不在场的人显示头像）
@choice
> 选项文本 => 标签 | bocchi+1
@set nijika+1
@if bocchi>=3 => 标签
@jump 标签
@route bocchi|nijika|ryo|kita|normal           ← 进入个人线时调用一次（标题画面会换图）
@ending bocchi|nijika|ryo|kita|normal
@credits cg图id
@wait 毫秒
@center 居中显示的独白（\n 换行）
名字：台词
旁白（不写名字）
（内心独白用全角括号）
```
硬性规则：
1. **角色在场说话，立绘必须在场**（或者在 CG 里）。不在场的人（电话、LINE、隔着门）用 @mode phone / @line。
2. 雨、雪粒子只用于户外背景。
3. 一行台词不超过 110 字。
4. 同时在场的立绘最多 4 个。
