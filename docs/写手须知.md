# 写手须知（个人线第四~六章）

你负责《孤独摇滚！ 第五条音轨》某一条个人线的第四、五、六章。共通线（第一~三章）已经写好，你要无缝接上。

## 先读这些（必须全部读完再动笔）
1. `docs/设定集.md` —— 世界观、人物、称呼表、说话风格、剧本格式、硬性规则
2. `docs/大纲.md` —— 全部分场大纲。你那条线的大纲是骨架，可以加细节、加场景、调整节奏，但关键事件和结局不能改
3. `script/01_ch1.js` `02_ch2.js` `03_ch3.js` —— 共通线全文。**文风、旁白的语气、幽默感、节奏，以这三章为准**。你的线必须能自然接在 `03_ch3.js` 最后的选择之后
4. `js/assets.js` —— 所有可用的背景、立绘表情、CG、结局 ID。**只能用这里有的 ID**
5. `js/audio.js` 里 `TITLES`（BGM 名）、`startAmb` 里的 `target`（环境音名）、`se()` 里的 `case`（音效名）

## 交付
- 只写你自己的那个文件（例如 `script/10_bocchi.js`）。不要修改任何其他文件。
- 格式：整个文件是 `SCRIPTS.push(String.raw\`` …… `\`);`，内容是剧本命令和台词（参考共通线文件）。
- 第一个标签就是入口（`*b4` / `*n4` / `*r4` / `*k4` / `*x4`），紧接着 `@route 路线名`。
- 你所有的标签和 `@node` id 都用你的前缀（`b4_` `b5_` `b6_` 之类），不要和别的文件撞名。
- 三章各用一次 `@chapter 第四章|标题|ENGLISH SUBTITLE`。
- 每个场景开头放 `@node 节点id|分支图上的短标题`（标题 2~8 个字）。一章大约 5~8 个节点。
- 结尾顺序：`@ending 路线名` → `@credits 一张CG的id` → `@totitle`。**一定要有 `@totitle`**，否则会掉进下一个文件。
- 写完后运行 `node tools/validate.js 你的文件名`（例如 `node tools/validate.js 10_bocchi`），把 ERRORS 全部修好，WARNINGS 里的「speaks without sprite」和「changes outfit」也要修到 0。
  - 这个校验会报 `missing label b4/n4/...`（指向别的线的入口）和 missing image files，这两类不是你的问题，可以忽略。

## 体量
- 个人线：显示文本约 **1.5 万字**（三章各约 5000 字）。普通线约 **1.1 万字**。宁可写满，不要写短。
- 每一章至少一个有分量的情感场面，至少一处让人笑出来的地方。

## 文风要求（重要）
- 旁白＝透的内心：冷静、克制、心里吐槽，常用声音和器材做比喻（推子、啸叫、底噪、混响、节拍器、磁带……）。不要写成华丽的抒情散文。
- 台词要短。像真人说话。不要让角色把主题直接说出来；让动作、声音、细节去说。
- 原作的味道：一里的崩坏和妄想（tint fantasy / despair、@show bocchi gag … melt、@se collapse）、凉的借钱和吃草、喜多的光环（@fx sparkle、@se kira）、虹夏的「可怕的笑」（nijika dark）、星歌的嘴硬、广井的醉话。搞笑和感动要交替。
- 多用共通线埋下的东西做回响：八字绕线、结束带、REC 红灯、储物间的「壁橱」、芒果箱、自动贩卖机前的可可、凉的借款本、第六小节、「下次，推上去」、「吉他想哭」、「为了不受伤」、群名「结束乐队＋1」、透明人间的评论……
- 不要引用任何真实歌曲的歌词（包括结束乐队的歌）。可以提歌名。「ハウリング」的歌词只写一两句意象，必须是原创的。
- 不写任何露骨内容。恋爱的最高潮是告白（最多一个很轻的吻或牵手）。

## 演出规则（上一作的教训，必须遵守）
1. **在场的角色说话时，她的立绘必须在画面上**（或者在 CG 里）。人多的时候用 p1~p4 或者轮流显示说话的人，同时最多 4 个立绘。
2. 不在场的人（电话、隔着门、广播）：`@mode phone` 打电话；LINE 用 `@line 群名` …… `@line off`。打电话前可以用 `@face 角色 表情` 指定头像表情。
3. **雨、雪粒子（@fx rain / heavyrain / snow）只能在户外背景**（assets.js 里 `out: true` 的背景）。室内的雨用环境音 `@amb rain` 表现就好。
4. **服装**：十二月的户外场景，四位女主用冬装立绘（一里 `winter_*`，其他三人 `coat_*`）；室内用制服立绘。同一个场景里不要换装，换场景（换 @bg）时才能换。冬装只有 normal/smile/blush/cry（凉是 normal/smile/sad/blush），在户外需要别的表情时，选最接近的冬装表情。
5. 一行台词不超过 110 字。长的心理描写拆成几行。
6. 每次 `@bg` 不带 `keep` 会清掉所有立绘和粒子，需要重新 `@show`。
7. 情绪高潮可以用 `close` 把立绘拉近（例如 `@show nijika coat_cry c close`）。
8. 选项：每章可以有 1 个小选项（只影响几句台词，不影响结局），格式见共通线。

## 别的女主的伏笔怎么处理
共通线给四个女主各埋了一个伏笔：虹夏想知道星歌的过去；凉在写一个不给人听的桥段；喜多看到「主唱的吉他好普通」的评论、偷偷练 solo；一里收到了制作人的私信。
- 在你的线里，你的女主的伏笔是主线。另外三个伏笔要轻轻收掉（一两句话、一个小场面即可），不要留下悬而未决的大坑。比如：一里说她已经把那封私信拒绝了／删了；凉的桥段写完了；喜多的 solo 练成了；虹夏终于问了星歌一句、星歌没多说。
- 在非一里线里，不要揭开「透就是透明人间」这件事（那是一里线的核心）。
